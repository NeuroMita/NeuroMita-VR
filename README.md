# NeuroMita VR

[Русский](README.md) · [English](README.en.md)

Экспериментальный внешний VR-мод для [NeuroMita](https://github.com/VinerX/NeuroMita): Windows x64, Unity IL2CPP, BepInEx 6 и OpenXR. Работает поверх собранной игры; отдельная VR-сборка игры и Unity Editor для запуска не нужны.

**Мод в активной разработке. Это ещё не готовая VR-версия с полным набором игровых возможностей.** В нём уже можно зайти в главное меню и квартиру, но ряд взаимодействий и окон требует адаптации. Репозиторий предназначен также для тех, кто хочет помочь с доработкой.

## Состояние

Проверено 17 октября 2026 года:

| Возможность | Статус |
|---|---|
| Чистый публичный релиз NeuroMita v2026.10.15 + внешний мод | Главное меню и квартира отображаются и обновляются в шлеме; подтверждено пользователем |
| OpenXR и контроллеры | Сессия и tracking запускаются; движение и подбор ранее подтверждены в отдельном тестовом host |
| Пауза и VR Settings | Реализованы; изображение этих панелей получено в тестовом host. Полная проверка настроек продолжается |
| Панель действий Миты, HUD | Исправляются ошибки слоя UI, геометрии IL2CPP и привязки к голове; проверка взаимодействий продолжается |
| Музыкальный проигрыватель | Интерфейс рисуется в текстуру; видимость, расположение и управление в VR ещё дорабатываются |
| TV / YouTube | Подготовлены проекция полного интерфейса и VR-ввод текста; проверка поиска, настроек и выхода в шлеме ещё не завершена |
| QTE, захваты Миты, отдых, бита и другие механики | Не имеют полного VR-покрытия; могут требовать клавиатуру или быть неудобны/недоступны |

Подтверждённый запуск меню и квартиры не означает, что всю игру можно пройти контроллерами. Список работ и критерии проверки: [аудит взаимодействий](docs/vr-interaction-audit.md). Техническая история проверок: [checkpoint](docs/checkpoint.md).

Пакет интерфейса 18 октября: кнопки Миты привязаны к её телу, показатели вынесены над головой при взаимодействии; добавлены проверка стен для панелей, проекция инструментов мольберта и русский язык VR-настроек. Эти изменения ещё ожидают проверки в шлеме. Рисование контроллером и встраивание VR-страницы в обычные настройки пока не реализованы.

## Совместимость

- Windows x64, IL2CPP, Unity **6000.3.12f1**.
- Проверенный публичный host: внутренняя версия **v2026.10.15**. Имя папки скачанного архива может отличаться от внутренней версии игры.
- Проверенный BepInEx: **6.0.0-be.788**, IL2CPP x64; Il2CppInterop **1.5.3**.
- Нативные файлы Unity OpenXR **1.16.1** и активный SteamVR OpenXR runtime.
- Текущий профиль ввода — **Oculus Touch**. Полная поддержка других контроллеров не подтверждена.

## Установка и запуск

1. Начните с отдельной копии совместимого публичного релиза игры.
2. Установите BepInEx 6 **Unity IL2CPP x64**. Один раз запустите игру для генерации `BepInEx/interop`, затем закройте её. Interop из другого билда не подходит.
3. Распакуйте **игровой** пакет `vr-mod-*.zip` в папку с `NeuroMita.exe`, сохраняя структуру. Если готового пакета у вас нет, соберите его по [инструкции разработчика](docs/development.md). Исходный ZIP репозитория сам по себе не является установочным пакетом.
4. Если ранее ставили `NeuroMita.XR.Probe.dll`, уберите его из `BepInEx/plugins`: диагностический probe нельзя запускать вместе с игровым VR-модом.
5. Проверьте `NeuroMita_Data/boot.config`: для проверенного публичного host нужна строка `xrsdk-pre-init-library=UnityOpenXR`. Если её нет, сохраните копию файла и добавьте строку один раз. Остальные параметры не заменяйте. Текущий упаковщик не добавляет эту строку автоматически.
6. Подключите шлем к ПК, запустите SteamVR, убедитесь, что шлем и контроллеры доступны, а SteamVR выбран OpenXR runtime.
7. Запустите `NeuroMita.exe`. Альтернатива — `Start-VrMod.ps1 -GameDirectory 'путь к игре'` из игрового пакета. VR включён по умолчанию; запуск runtime ожидает готовности меню или игрока.

Игра, BepInEx и generated interop не входят в пакет мода. Подробности и структура файлов: [установка игрового пакета](docs/gameplay-package.md). [XR probe](docs/installation.md) — отдельная диагностика, а не игровой мод.

## Управление Touch

| Контроллер | Действие |
|---|---|
| Левый стик | Движение |
| Правый стик | Поворот |
| Правый trigger | Нажатие/перетаскивание интерфейса лучом |
| Правый grip | Взаимодействие |
| Правый A | Прыжок / отправка чата в соответствующем контексте |
| Правый B | Меню действий |
| Левый X | Чат |
| Левый Y | Пауза / назад; выход из TV-мини-игр |
| Левый trigger | Инвентарь |
| Левый grip | Push-to-talk |
| Нажатие правого стика | Показать/скрыть подсказки |
| Удерживать нажатия обоих стиков | Центрирование |

Настройки доступны через **Настройки VR / VR Settings** в паузе и сохраняются в `BepInEx/config`. Это текущая раскладка; контекстные конфликты и все перечисленные действия ещё не прошли полную приёмку. Клавиатурные подсказки в некоторых сценариях пока сохраняются.

## Отключение и диагностика

- Для обычного запуска используйте `NeuroMita.exe --no-vr` либо установите `General / Enabled = false` в конфигурации плагина после закрытия игры.
- Для удаления игрового плагина закройте игру и уберите каталог `BepInEx/plugins/NeuroMitaVRmod`. Общие файлы BepInEx/OpenXR могут использовать другие моды; восстанавливайте их по своей резервной копии и перечню файлов пакета.
- При проблеме сохраните версию игры/мода, модель шлема, способ PCVR-подключения и шаги воспроизведения. Логи: `BepInEx/LogOutput.log` и Unity `Player.log`. Перед публикацией проверьте их на личные данные и локальные пути.
- `OpenXR active` в логе подтверждает этап запуска, но не правильное изображение и управление. Отладочные средства описаны в [debugging](docs/debugging.md).

## Разработка и помощь проекту

Игровой runtime находится в этом репозитории, в `src/NeuroMita.VR.Runtime`; bootstrap — в `src/NeuroMitaVRmod`. DLL собираются без Unity Editor, против interop соответствующего host. Изменения разрабатываются и проверяются как мод. [Unity VR-ветка](https://github.com/VinerX/NeuroMita-Unity/tree/codex/neuromita-vr) остаётся источником сравнения, а не обязательной зависимостью сборки DLL.

- [Сборка, аудит IL2CPP и упаковка](docs/development.md).
- [Исходники ресурсов и готовый AssetBundle](assets/README.md). Editor нужен для изменения/пересборки ресурсов.
- [Происхождение исходников](docs/source-provenance.md), [сторонние зависимости](THIRD_PARTY_NOTICES.md).

Для доработок полезны небольшие изменения по одному сценарию с описанием: какой host использован, что проверено статически, что реально проверено в шлеме и что остаётся открытым. DLL игры, interop, кэши, локальные конфиги, логи и дампы не коммитятся.
