# Установка экспериментального игрового VR-мода

Это игровой runtime, а не XR probe. На 2026-10-17 пользователь подтвердил главное меню и квартиру в шлеме на чистом публичном host v2026.10.15 (Windows x64 IL2CPP, Unity 6000.3.12f1) с внешним модом. Ранее использовался validation host 46d89dce1. Полная приёмка игровых взаимодействий не завершена; совместимость с другими релизами не гарантируется. Начните с отдельной копии игры.

1. Установите BepInEx 6 для Unity IL2CPP x64. Проверенный baseline: 6.0.0-be.788, Il2CppInterop 1.5.3. Запустите обычную игру один раз для генерации interop, затем закройте её.
2. Распакуйте игровой vr-mod ZIP в папку с NeuroMita.exe с сохранением структуры. Не переносите interop из чужого билда.
3. Если ранее ставили NeuroMita.XR.Probe.dll, переместите его из BepInEx/plugins в другую папку. Он может находиться непосредственно в plugins или во вложенном каталоге.
4. Подключите шлем к ПК, запустите SteamVR и убедитесь, что SteamVR видит шлем и контроллеры. SteamVR должен быть активным OpenXR runtime.
5. Для проверенного публичного host проверьте NeuroMita_Data/boot.config: нужна строка xrsdk-pre-init-library=UnityOpenXR. Если её нет, сохраните резервную копию и добавьте строку один раз, не заменяя остальные настройки. Текущий ZIP не содержит host boot.config и не меняет его автоматически.
6. Запустите NeuroMita.exe из этой копии игры. Отдельная команда Unity Editor не требуется. Альтернатива: .\Start-VrMod.ps1 -GameDirectory 'путь к игре'.

Bootstrap по умолчанию включает VR и ждёт готовности меню или игрока и окончания перехода сцены перед запуском внешнего runtime. Его настройки сохраняются в BepInEx/config. При ошибке смотрите BepInEx/LogOutput.log и Unity Player.log. Строки Native session creation: True, Touch controller actions attached, Native XR display=True, input=True и OpenXR active подтверждают этапы запуска, но не качество изображения и физического управления.

Базовая раскладка Touch: левый стик — движение, правый — поворот; правый trigger — указатель, grip — взаимодействие; A — прыжок/подтверждение чата, B — radial menu; X — чат, Y — пауза; левый trigger — инвентарь, grip — микрофон. Одновременное удержание обоих стиков — recenter. Движение и подбор ранее подтверждены на validation host. Полная проверка всех действий и контекстов продолжается.

Пакет содержит bootstrap DLL, runtime DLL, AssetBundle, нативные UnityOpenXR/openxr_loader и subsystem manifest. Игра, BepInEx и generated interop в ZIP не входят. Уведомления Unity OpenXR сохранены в Notices. Перед публичной раздачей ресурсов из Unity-проекта отдельно проверьте права на них: лицензия кода NeuroMita их не перелицензирует; SOURCE_PROVENANCE.md включён в пакет.

Ограничения: публичный host прошёл проверку отображения меню и квартиры; полная проверка действий в доме, смартфона, радио, QTE и TV не завершена. Native controller profile пока только Oculus Touch. Не переносите ограничения старого validation host на текущий публичный релиз без проверки. Текущий список задач — [аудит взаимодействий](vr-interaction-audit.md).
