# Подготовка к публичному репозиторию

Репозиторий содержит исходники прототипа и документацию. Публикация GitHub-репозитория, смена visibility и выпуск бинарного релиза — отдельные действия; подготовка файлов их не выполняет.

## Включено в исходники

Bootstrap, диагностический плагин, проект игрового runtime с IL2CPP-адаптерами, скрипты упаковки/запуска и документация с явными ограничениями.

## Исключено из Git

Локальный SDK, игровые файлы и *_Data, BepInEx, сгенерированный interop, DLL/EXE/PDB и архивы, bin/obj/dist, env-файлы и настройки IDE, дампы, скриншоты и сырые логи docs/evidence.

.gitignore не удаляет уже закоммиченные файлы и не очищает историю. Перед первым push просмотрите:

    git status --short
    git ls-files
    git log --all --stat
    git diff --cached --check

Текущая подготовка не удаляет локальные диагностические артефакты. Они остаются на диске, чтобы не потерять рабочие результаты.

## Что ещё требуется перед объявлением публичного проекта

- Для кода и документации выбрана лицензия NeuroMita, точная копия в LICENSE; происхождение ресурсов и зависимости описаны отдельно.
- Remote подключён к https://github.com/NeuroMita/NeuroMita-VR. Публичность репозитория меняет владелец.
- Проверить полный список staged-файлов и историю на личные данные/секреты.
- Не публиковать игровой ZIP или OpenXR/BepInEx-зависимости вместе с исходниками без отдельной проверки их состава и уведомлений.
- Сохранить статус «work in progress»: отсутствие полноценной проверки изображения и управления в шлеме должно быть видно до инструкции установки.

Сырой лог с локальным путём не становится безопасным для публикации от одного добавления в .gitignore. При необходимости публикуйте только вручную проверенную короткую выдержку без личных путей и идентификаторов.

Исключение для ресурсов: assets/prebuilt/neuromita-vr-assets намеренно хранится в обычном Git вместе с исходниками assets/source. Его размер около 160 КиБ; это не игровые DLL или полный архив игры. Происхождение кистей указано в docs/source-provenance.md.
