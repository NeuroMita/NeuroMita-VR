Каталог src/NeuroMita.VR.Runtime/Gameplay первоначально перенесён из Assets/Scripts/NeuroMitaScripts/VR проекта VinerX/NeuroMita-Unity, ревизия b89701b7d, ветка codex/neuromita-vr: 30 runtime C# файлов. После переноса код развивается независимо в репозитории мода.

По решению автора код и документация мода используют ту же лицензию NeuroMita, что и канонический проект: текст Licence.md сохранён в корневом LICENSE. Сохраняются авторство, активная ссылка на основу и условия для материалов, получаемых отдельно. Это не утверждение, что весь Unity-проект или сторонние материалы стали MIT.

assets/source содержит минимальный Unity-проект с двумя мешами кистей, материалами, comfort shader и скриптом сборки. Меши извлечены из Assets/NeuroMita/FBX/Player/PlayerModelNewTest.fbx с помощью VrHandMeshBuilder Unity-полигона. Полный FBX, текстуры персонажей, сцены и prefab игры не включены. Эти меши не объявляются оригинальной геометрией мода; лицензия кода не предоставляет прав на сторонние модели и другие материалы MiSide. Их условия учитываются отдельно при распространении.

assets/prebuilt содержит готовый Windows64 bundle из установленного тестового мода и provenance.json с версией Unity, хешами и происхождением исходников. Подготовленный минимальный asset-проект ещё не проходил импорт/пересборку в Editor; включённый bundle не выдаётся за результат такой проверки.

DLL собираются без Unity checkout при наличии совместимого host interop и BepInEx core. Пакет мода использует включённый bundle, а Unity Editor требуется для его изменения. OpenXR native files предоставляются отдельно с собственными уведомлениями.
