# Происхождение исходников VR

Каталог src/NeuroMita.VR.Runtime/Gameplay первоначально перенесён из Assets/Scripts/NeuroMitaScripts/VR проекта VinerX/NeuroMita-Unity, ревизия b89701b7d (ветка codex/neuromita-vr). Перенесены 30 runtime C# файлов без Editor, сцен, prefab, моделей персонажей и прочей игры. После переноса код Gameplay развивается в репозитории мода; изменения не синхронизируются автоматически.

Сборка runtime больше не использует UnityProjectDir. Unity checkout нужен только как необязательный источник уже собранного AssetBundle и официального пакета OpenXR при упаковке. DLL можно собрать при наличии host interop и BepInEx core без Unity Editor.

Авторские права на исходные материалы сохраняются. MIT в корне относится к собственным исходникам мода и не заменяет лицензии сторонних компонентов или ресурсов. В выбранной исходной ревизии не найден корневой LICENSE/COPYING; перед публикацией перенесённой Gameplay-части следует явно подтвердить её лицензионный статус с правообладателем проекта. Это не препятствует локальной разработке, но нельзя автоматически считать всю игру MIT.

Ресурсы кистей/материалов остаются в отдельном AssetBundle, не коммитятся как бинарники. При публичной раздаче пакета права на них проверяются отдельно.
